# Lakshmi Nivas KT Hotel

A modern, responsive website created to showcase the heritage, signature KT Tea, food, story, and overall experience of **Lakshmi Nivas KT Hotel**.

## 🌐 Project Overview

This project presents a traditional hotel and its long-standing identity through a modern digital experience.

The website allows visitors to:

* Explore the hotel's story and heritage
* Learn about its signature KT Tea
* Discover food and snack offerings
* View photographs and memorable moments
* Learn about its legacy and journey
* Explore the hotel's experience through a modern interface
* Find important visitor information

The design combines a traditional character with a clean, modern web experience.

---

## ✨ Features

### 🏛️ Heritage & Story

A dedicated section presenting the hotel's history, legacy, and journey.

### ☕ Signature KT Tea

Highlights the hotel's distinctive KT Tea and its traditional preparation and presentation.

### 🍽️ Food

Showcases selected food and snack offerings.

### 📸 Gallery

A visual gallery featuring the hotel's tea, food, heritage, and atmosphere.

### 🕰️ Legacy Timeline

A timeline-based presentation of important stages in the hotel's journey.

### 🏗️ Rebuilding Story

Presents the hotel's rebuilding journey and continuation of its traditional identity.

### 📍 Visit Information

Provides useful information for visitors through a dedicated visit section.

### 📱 Responsive Design

The website is designed to work across:

* Mobile
* Tablet
* Laptop
* Desktop

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ashwithkumar404-glitch/Lakshmi-Nivas-KT-Hotel-project.git
```

### Enter the project directory

```bash
cd Lakshmi-Nivas-KT-Hotel-project
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

---

## 📦 Production Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🎨 Design Approach

The website follows a **heritage-meets-modern** design approach.

It combines:

* Warm, traditional visual tones
* Heritage-focused imagery
* Clean typography
* Modern layouts
* Large visual sections
* Responsive design
* Simple navigation
* Story-driven content

The goal is to preserve the traditional character of the hotel while presenting it through a modern digital experience.

## ☕ About KT Tea

KT Tea is one of the central elements of the hotel's identity.

The website presents its distinctive layered appearance, traditional preparation, and role in the hotel's story through a dedicated interactive section.
